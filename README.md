# HRMS4ODOO — Dayflow

Human Resource Management System, built for the Odoo Hackathon.

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- React Router, TanStack Query, React Hook Form, Zod, Recharts
- Supabase: Auth, PostgreSQL, Row Level Security, Storage

## Status

Initial repository scaffold only. Product blueprint and feature work begin after team approval.

## Getting Started

Run: npm install, then npm run dev
